Лабораторная работа №1
Целью данной работы является реализация классического алгоритма перемножения матриц на языке C++ и анализ его эффективности. В ходе работы исследуется зависимость времени выполнения от размера матриц.
В программе реализован алгоритм с перестановкой циклов i-k-j. В данном случае Матрица A читается последовательно. Это позволяет процессору эффективно использовать кэш-линии.
Тестирование проводилось для матриц размера: 200, 400, 800, 1200, 1600, 2000.
